# Thumbnail prompt

- Témaazonosító: `2-unlimited-claude-code-for`
- Videócím: **Claude Code limitbe futott? Próbáld helyi modellel**
- Pain point: a Claude Code munkamenet a használati keret elfogyása miatt megáll.
- Rövid képfelirat: **Elfogyott a keret?**
- Képötletek:
    - A készítő meglepett arccal egy terminált néz, amelyen a használati limit elérése látszik; mellette egy laptopon futó egyszerű kalkulátor.
    - A készítő egy Ollama-modellt jelölő helyi gép és egy megállt felhőkapcsolat között mutat választási irányt.
- Végső képgeneráló prompt: „Készíts 16:9 arányú, jól olvasható YouTube-thumbnailt a ‘Claude Code limitbe futott? Próbáld helyi modellel’ videóhoz. A képen szerepeljen a videó készítője; ha referenciaportré van mellékelve, őrizd meg felismerhető arcvonásait. A készítő meglepett, de magabiztos arccal a terminálban megjelenő ‘LIMIT’ figyelmeztetésre mutat, mellette egy laptopon egyszerű ajánlati kalkulátor látszik. A képfelirat pontosan: ‘Elfogyott a keret?’ Kontrasztos, kevés elemből álló kompozíció, a felirat mobilon is jól olvasható. Ne sugallja, hogy Anthropic Claude fut helyben, ne ígérjen végtelen használatot, ne jelenítsen meg hamis márkalogót vagy olvashatatlan terminálszöveget.”
- Hook-visszaigazolás: a hook első mondata kimondja a keret elfogyásának problémáját, a következő mondatrész pedig megígéri a helyi modellel való csatlakoztatás bemutatását és egy tényleges demópróbát.
