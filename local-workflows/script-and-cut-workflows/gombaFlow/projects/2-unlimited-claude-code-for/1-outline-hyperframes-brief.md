# Outline animációs brief — Hyperframes

- Témaazonosító: `2-unlimited-claude-code-for`
- Videócím: **Claude Code limitbe futott? Próbáld helyi modellel**
- Pain point: a Claude Code munkamenet a használati keret elfogyása miatt megáll.
- Animálandó bulletpointok, sorrendben:
    - Megnézzük, mit jelent a Claude Code keretének elfogyása, és mi fut helyben.
    - Összekötjük a Claude Code-ot egy, a Macünkhöz választott Ollama-modellel.
    - Elkészítünk és kipróbálunk egy kis Gomba Limited árrés-kalkulátort.
    - Megmutatom, milyen kompromisszumokkal jár a helyi modell, és mikor érdemes másik utat választani.
- Hyperframes prompt: a négy pont közvetlenül a hook után, egyenként és pontosan a fenti sorrendben jelenjen meg. A szöveghez és jelentéshez ne nyúlj; minden pont kapjon letisztult, egyértelmű ikonikus mozgású megjelenést, majd maradjon olvasható, amíg felolvassuk. A videócím és a keret elfogyásának pain pointja legyen a vizuális keret. Ne sugalljon olyan teszteredményt, amelyet a készítő még nem igazolt.
