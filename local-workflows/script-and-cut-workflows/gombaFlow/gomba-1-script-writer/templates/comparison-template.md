# Előtte és utána

Az alábbi szempontok neve és sorrendje kötött. A cellákat a témához kell kitölteni;
nem értelmezhető sornál rövid „nem releváns” indok kerüljön a tervbe,
de az ne váljon üres felsorolássá a narrációban.

| Szempont          | Előtte                                    | Utána                                              |
| ----------------- | ----------------------------------------- | -------------------------------------------------- |
| Kézi lépések      | [Mit végez az ember?]                     | [Mi automatizált, mi marad kézi?]                  |
| Időráfordítás     | [Igazolt idő vagy rövid minőségi leírás.] | [Igazolt idő vagy rövid minőségi leírás.]          |
| Hibalehetőség     | [Konkrét kézi hibaforrás.]                | [Mit kezel a rendszer, milyen kockázat marad?]     |
| Költség           | [Emberi munka és eszközök.]               | [Szolgáltatás, API, hosting és emberi ellenőrzés.] |
| Emberi felügyelet | [Mit kell figyelni, eldönteni?]           | [Hol szükséges beavatkozás vagy jóváhagyás?]       |

- Cellánként legfeljebb egy rövid mondat, párhuzamos megfogalmazással.
- A rövid listapontok egyenként képernyőre vihetők; grafikai terv nem készül.
- Az állítások bizonyítását a [közös szabályok](../CONTENT_RULES.md) határozzák meg.
